# Vendored cubiomes

Unmodified copy of https://github.com/xpple/cubiomes (MIT), a maintained fork
of Cubitect/cubiomes that adds Minecraft 1.21.4 through 26.3 (sulfur caves,
dappled forest, abandoned camps).

- Commit: 18edd56575a60fe7129705bf972de0a511437527 (2026-09-22)

To update, replace this directory with a newer `git archive` of that repo,
update the commit above, and rebuild with `cli/build.sh`. Don't edit files
here. Local code belongs in `cli/`.
