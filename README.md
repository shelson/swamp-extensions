# swamp-extensions

My extensions for Swamp Club — https://swamp-club.com/u/shelson

## Extensions

| Extension | Description | Install |
| --- | --- | --- |
| [docker-compose-refresher](docker-compose-refresher/) | Keep `:latest`-tagged services in local or SSH-reachable Docker Compose projects up to date | `swamp extension pull @shelson/docker-compose-refresher` |
| [k3s](k3s/) | Install and operate k3s on a local or SSH-reachable host; exports a kubeconfig for `@swamp/kubernetes` | `swamp extension pull @shelson/k3s` |
| [newrelic](newrelic/) | New Relic entity model types (dashboards, alerting, synthetics, notifications) backed by the NerdGraph GraphQL API | `swamp extension pull @shelson/newrelic` |
